Tool Call Event
The conversation.tool_call event is emitted by Tavus over the conversation's data channel (Daily app-message) when the LLM decides to invoke a tool you defined in layers.llm.tools. Your application listens for this event, executes the corresponding logic, and returns results to the conversation via a conversation.echo or conversation.append_llm_context interaction. Tavus does not execute tool calls on the backend — your app is responsible for running the tool and sending back the result. The event payload identifies the conversation and includes the tool/function name and the arguments the model supplied (matching the JSON Schema you declared for that function).
