Create Guardrails
Create a new guardrail. Guardrails provide strict behavioral boundaries that are enforced throughout a conversation. Attach guardrails to a persona directly via `guardrail_ids` or by tag via `guardrail_tags` on Create Persona (/api-reference/personas/create-persona). For AI agents, use https://docs.tavus.io/openapi.yaml for the full HTTP API contract.
